💼 Business Problem & Executive Value Proposition

⚠️ The Business Challenge in Hospitality Revenue Management

Hotel revenue directors and property managers frequently suffer from fragmented reservation systems, delayed month-end financial reconciliations, and opaque cancellation impacts. Making timely pricing and yield management decisions is nearly impossible when metrics like Average Daily Rate (ADR), Realized Revenue, and Occupancy Rates are locked in disparate operational silos.

✨ The Engineered Solution

This platform bridges transactional booking management and high-level financial intelligence. By executing optimized analytical JPQL queries at the database engine tier, it delivers instant visibility into multi-property revenue yields, status distributions, and monthly time-series projections with zero manual spreadsheet reconciliation.

🏛️ Full-Stack Layered Architecture & Tech Stack

Engineered using a decoupled microservices architecture with an Angular 19 reactive single-page application and a Spring Boot 3 Java 22 REST service.

🅰️

Angular 19 & TypeScript

Standalone reactive components, RxJS Observables, Chart.js time-series visualizations, and reverse-proxy routing.

🍃

Spring Boot 3.2.3 & Java 22

Spring Web REST controllers, Jakarta Bean Validation, RFC-7807 global exception handling, and custom JPQL repositories.

🗄️

H2 In-Memory & MySQL 8.0

High-speed analytical database with automatic schema migrations, data indexing, and idempotent sample data loader.

📑

OpenAPI 3.0 & Swagger UI

Interactive self-documenting REST contract explorer with live query execution and schema definitions.

Executive Dashboard Overview

2

Interactive Visualizations

Hover over the Monthly Revenue Trend line chart and Occupancy Status donut chart. Point out the property performance leaderboard.

3

Multi-Property Date Filtering

Click on the Date-Range Presets (This Month, Last 3 Months) to demonstrate real-time client-side dataset filtering.

4

Live Reservation CRUD Flow

Go to Bookings. Create a new reservation with instant date validation (e.g. Check-out > Check-in). Observe the floating toast notification and automatic table reload.

5

Deep-Dive Analytics & Swagger

Switch to Analytics to inspect the dynamic Top N hotel selector (Top 3, Top 5, Top 10). Click the Swagger button in the navbar to show the live OpenAPI explorer.
